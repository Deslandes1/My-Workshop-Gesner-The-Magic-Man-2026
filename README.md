## What it does

- Shows a personal hub page with my name at the top
- Lists every HTML app stored in the `apps/` folder as a card
- Lets me open any app right inside the page
- Lets me upload new HTML apps directly from the browser
- Persists `localStorage` reliably because apps are served over HTTPS
